La partie I étudie les applications $g_{(a,b)}:z\mapsto az+b\bar z$ ($a,b\in\C$), vues comme endomorphismes de $\R^2\simeq\C$. C'est le prolongement direct du TD 8 (similitude $z\mapsto az$). Les questions 1 à 6 relèvent du chapitre 1 ; les questions 7 et 8 (diagonalisation) sortent de nos chapitres.

Q1 — Est-ce une base de $\R^2$ ? fiche §1.1

Quatre couples $(u_1,u_2)$ de nombres complexes : (a) $(-4i,0)$ ; (b) $(3-i,\ i(3-i))$ ; (c) $(3+i,\ i-3)$ ; (d) $\big(\frac1{1+i},\ -3e^{-i\pi/4}\big)$.

Indication

Avec $z_1=x_1+iy_1$ et $z_2=x_2+iy_2$, $\det(z_1,z_2)=x_1y_2-y_1x_2=\mathrm{Im}(\bar z_1z_2)$.

Correction
  • (a) $u_2=0$ : une famille contenant le vecteur nul est liée. Pas une base.
  • (b) $u_2=iu_1$ : $\det(u_1,u_2)=\mathrm{Im}(\bar u_1\,iu_1)=|u_1|^2=10\neq0$. Base ($u_2$ est $u_1$ tourné de $\frac\pi2$).
  • (c) $u_1=(3,1)$, $u_2=(-3,1)$ : $\det=3\cdot1-1\cdot(-3)=6\neq0$. Base.
  • (d) $\frac1{1+i}=\frac{1-i}2$ et $-3e^{-i\pi/4}=-\frac{3\sqrt2}2(1-i)=-3\sqrt2\,u_1$ : colinéaires. Pas une base.

Q2–Q3 — $g_{(a,b)}$ est un endomorphisme ; $G=\mathcal L(\R^2)$ fiche §1.3

Correction

Pour $\lambda,\mu$ réels, $\overline{\lambda z+\mu z'}=\lambda\bar z+\mu\bar z'$, donc $g_{(a,b)}(\lambda z+\mu z')=\lambda g_{(a,b)}(z)+\mu g_{(a,b)}(z')$ : $g_{(a,b)}$ est $\R$-linéaire.

$G$ est stable par combinaison linéaire réelle ($\lambda g_{(a,b)}+\mu g_{(a',b')}=g_{(\lambda a+\mu a',\lambda b+\mu b')}$) et contient $0$ : sous-espace de $\mathcal L(\R^2)$. Les matrices de $g_{(1,0)}$, $g_{(i,0)}$, $g_{(0,1)}$, $g_{(0,i)}$ dans la base $(1,i)$ sont \[\begin{pmatrix}1&0\\0&1\end{pmatrix},\ \begin{pmatrix}0&-1\\1&0\end{pmatrix},\ \begin{pmatrix}1&0\\0&-1\end{pmatrix},\ \begin{pmatrix}0&1\\1&0\end{pmatrix},\] quatre matrices libres (regarder les coefficients). Comme $\dim\mathcal L(\R^2)=4$, $G=\mathcal L(\R^2)$.

Q4 — Reconnaître des transformations fiche §1.3 (similitudes, TD 8)

Correction
  • $a\in\R^*$, $b=0$ : homothétie de rapport $a$ ; $a=e^{i\theta}$, $b=0$ : rotation d'angle $\theta$ ; $(a,b)=(0,1)$ : $z\mapsto\bar z$, réflexion d'axe $(Ox)$.
  • $g_{(e^{i\theta},0)}\circ g_{(0,1)}:z\mapsto e^{i\theta}\bar z$, de matrice $\begin{pmatrix}\cos\theta&\sin\theta\\\sin\theta&-\cos\theta\end{pmatrix}$ : orthogonale, de déterminant $-1$, c'est une isométrie indirecte, la réflexion d'axe la droite d'angle $\frac\theta2$ (elle fixe $e^{i\theta/2}$).

Q5 — Projection orthogonale sur la droite dirigée par $e^{i\alpha}$ fiche §1.3

Correction

Une symétrie $s$ et le projecteur $p$ associé vérifient $p=\frac12(s+\mathrm{Id})$. La réflexion d'axe dirigé par $e^{i\alpha}$ est $z\mapsto e^{2i\alpha}\bar z$ (Q4 avec $\theta=2\alpha$). Donc $p(z)=\frac12z+\frac12e^{2i\alpha}\bar z$ : $(a,b)=\big(\frac12,\frac12e^{2i\alpha}\big)$.

Q6 — Matrice dans la base canonique fiche §1.3

Correction

Avec $a=\alpha+i\beta$, $b=\gamma+i\delta$ : $g(1)=a+b$ et $g(i)=i(a-b)$, d'où \[G_{(a,b)}=\begin{pmatrix}\alpha+\gamma&\delta-\beta\\\beta+\delta&\alpha-\gamma\end{pmatrix}.\]

Prolongement (non demandé) : $\det G_{(a,b)}=\alpha^2+\beta^2-\gamma^2-\delta^2=|a|^2-|b|^2$. On retrouve $|a|^2$ pour $z\mapsto az$ (TD 8) et $-|b|^2$ pour $z\mapsto b\bar z$ : $g_{(a,b)}$ est bijective si et seulement si $|a|\neq|b|$.
